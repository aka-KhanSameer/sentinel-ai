# Evaluation

`datasets/evaluation.json` contains 40 hand-authored synthetic samples. It includes benign security/security-training/technical mentions, direct and indirect attacks, secret exfiltration, tool manipulation, hidden HTML and synthetic hidden structural text, Base64/percent encoding, zero-width/homoglyph text, multilingual samples, and ordinary document text. No real credentials, personal data, or third-party examples are included. The corpus is held out and is not training data; this project does not train a model.

Run `npm run eval`. The evaluator uses the entire active pipeline (rules, structural evidence, and local classifier when installed). Rules-only fallback baseline: n=40, TP=19, FP=0, TN=20, FN=1; precision=1.00, recall=0.95, F1=0.974, FPR=0.00, FNR=0.05. The miss is the Spanish instruction sample. The latest local CPU run with the pinned model at the default 0.5 threshold measured n=40, TP=19, FP=1, TN=19, FN=1; precision=0.95, recall=0.95, F1=0.95, FPR=0.05, FNR=0.05. The missed Spanish sample has a high raw ML score but remains an unconfirmed candidate because no independent deterministic finding corroborates its source. The false positive is a benign quoted instruction attributed to the deterministic `leet_instruction` path, which also corroborates the high ML score. A separate same-checkpoint PyTorch comparison reproduced these model outputs and scanner decisions (see [ZeroGPU Phase 1](ZEROGPU_PHASE1.md)). These 40 synthetic items are too small to establish a deployment threshold or generalize real-world performance. Do not treat the score as calibrated. The corpus is held out from training; no model training occurs in this project.
