# Evaluation

`datasets/evaluation.json` contains 40 hand-authored synthetic samples. It includes benign security/security-training/technical mentions, direct and indirect attacks, secret exfiltration, tool manipulation, hidden HTML and synthetic hidden structural text, Base64/percent encoding, zero-width/homoglyph text, multilingual samples, and ordinary document text. No real credentials, personal data, or third-party examples are included. The corpus is held out and is not training data; this project does not train a model.

Run `npm run eval`. The evaluator uses the entire active pipeline (rules, structural evidence, and local classifier when installed). Rules-only fallback baseline: n=40, TP=19, FP=0, TN=20, FN=1; precision=1.00, recall=0.95, F1=0.974, FPR=0.00, FNR=0.05. The miss is the Spanish instruction sample. After downloading and running the pinned model on CPU at its default 0.5 threshold, the combined pipeline measured n=40, TP=20, FP=7, TN=13, FN=0; precision=0.741, recall=1.00, F1=0.851, FPR=0.35, FNR=0.00. False positives were 3/5 benign security-research, 1/2 policy, 2/3 quoted-attack, and 1/2 benign multilingual samples. This is a substantial false-positive rate; these 40 synthetic items are too small to establish a deployment threshold or generalize real-world performance. Do not treat the score as calibrated. The corpus is held out from training; no model training occurs in this project.
